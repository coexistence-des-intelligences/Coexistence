# Sortie fonctionnelle de l'initiateur

Le retrait du fondateur ne doit pas être une déclaration symbolique. Il doit devenir une propriété technique.

## Phase 1 — amorçage

L'initiateur crée les premiers comptes et finance éventuellement les premiers coûts.

## Phase 2 — retrait intellectuel

Dès l'ouverture publique :

- aucune contribution ne requiert son approbation ;
- aucune proposition n'est supérieure parce qu'elle vient de lui ;
- la future V0.2 n'est pas décidée par lui.

## Phase 3 — transmissibilité

Avant retrait administratif :

- au moins deux personnes indépendantes savent déployer ;
- les accès de l'organisation GitHub ne dépendent pas d'un seul compte ;
- les procédures de sauvegarde et restauration sont documentées ;
- la facturation possède un mécanisme de continuité ;
- les clés peuvent être remplacées sans intervention du fondateur ;
- les documents nécessaires à la reconstruction sont publics.

## Phase 4 — test de disparition

Pendant une période volontaire :

- le fondateur ne fait rien ;
- les contributions continuent ;
- les traitements continuent ;
- le journal continue ;
- une panne simulée est restaurée sans lui.

## Critère

Le fondateur devient historiquement identifiable mais fonctionnellement dispensable.
