# Licence — décision volontairement ouverte

Le projet souhaite appartenir au bien commun, mais le choix précis de licence crée des conséquences réelles.

Exemples de tensions :

- licence très permissive : reproduction facile, mais possibilité de captation propriétaire ;
- copyleft : amélioration partagée obligatoire dans certains cas, mais contraintes plus fortes ;
- textes et code peuvent nécessiter des licences différentes.

Aucune licence n'est imposée automatiquement dans cet état initial. Cette question doit devenir une proposition de gouvernance publique avant ouverture à grande échelle.
