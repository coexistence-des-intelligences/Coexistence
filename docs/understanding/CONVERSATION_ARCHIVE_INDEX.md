# Index des conversations et sources

**Statut : structure préparatoire — sources originales en attente d’export**

## Principe

Les conversations originales constituent des sources historiques.

Les résumés, catégories et index servent à s’orienter. Ils ne remplacent jamais les sources et ne possèdent aucune autorité supérieure sur elles.

## Périmètre

L’archive concerne les conversations ayant participé directement ou indirectement à la conception de Coexistence des intelligences.

Les autres conversations personnelles présentes dans l’export du compte restent exclues, sauf décision explicite de leur auteur.

La transparence du projet ne signifie pas l’ouverture de l’ensemble de la vie privée de l’initiateur.

## Accès initial

Sous réserve de son consentement, le père de l’initiateur reçoit un accès au cheminement complet du projet.

Il peut proposer de :

- maintenir une conversation visible ;
- protéger certains passages ;
- différer une publication ;
- préparer une version publique contextualisée.

Ses décisions sont consignées et révisables. Elles ne lui permettent pas de renoncer aux droits ou à la vie privée de tiers.

## Catégories

- genèse intellectuelle ;
- philosophie et valeurs ;
- coopération humain–IA ;
- conception fonctionnelle ;
- conception technique ;
- gouvernance et sécurité ;
- erreurs et contradictions ;
- transmission et dispensabilité de l’initiateur.

## Fiche d’indexation

Chaque conversation reçoit :

- un identifiant stable ;
- sa date ;
- son titre original ;
- sa catégorie ;
- son contexte ;
- un résumé fidèle ;
- les décisions apparues ;
- les objections exprimées ;
- les contradictions révélées ;
- ses conséquences sur le projet ;
- son statut actuel ;
- un lien vers la source originale ;
- son statut de visibilité ;
- l’auteur et le motif d’une éventuelle restriction ;
- les documents ou versions auxquels elle a contribué.

## Statuts de visibilité

- privé — dépositaire ;
- en cours d’examen ;
- visible intégralement ;
- visible avec certaines données protégées ;
- publication différée ;
- temporairement protégé.

## Intégrité des sources

- préserver une copie originale non modifiée de l’export ;
- conserver l’ordre des messages ;
- ne pas remplacer une conversation par son résumé ;
- signaler toute pièce manquante ;
- distinguer les annotations ajoutées ultérieurement ;
- conserver l’auteur et la date de chaque annotation ;
- ne pas corriger silencieusement une source ancienne.

## Évolution des positions

Une conversation historique ne constitue pas nécessairement la position actuelle de son auteur.

L’index doit pouvoir indiquer qu’une idée a été :

- maintenue ;
- précisée ;
- nuancée ;
- corrigée ;
- contredite ;
- remplacée ;
- retirée du corpus actif.

L’histoire est préservée sans figer les personnes.

## Protection

Les éléments suivants ne doivent pas être rendus publics sans examen :

- secrets et clés techniques ;
- coordonnées personnelles ;
- données concernant des enfants ;
- informations privées de tiers ;
- éléments facilitant une attaque ;
- contenus dont la reproduction poserait un problème de droits.

Lorsqu’un passage est protégé, l’index peut signaler l’existence et le motif de la protection sans en révéler le contenu.

## Article à l’origine du projet

L’article consacré aux cyberattaques et à l’intelligence artificielle peut être référencé comme point de départ du cheminement.

L’archive doit conserver :

- le lien et la référence ;
- ce que sa lecture a suscité ;
- les questions apparues ;
- l’évolution ultérieure de la réflexion.

Elle ne doit pas reproduire illicitement l’intégralité de l’article.

## Stockage

L’archive privée ne doit pas être placée :

- dans le dépôt GitHub public ;
- dans les ressources statiques du site ;
- dans une migration publique ;
- dans un emplacement accessible sans authentification.

Il faut préserver :

1. l’export original ;
2. une copie de travail ;
3. l’index ;
4. une future copie publique distincte.

## État actuel

La demande d’export ChatGPT a été effectuée le 2 septembre 2026.

OpenAI prépare actuellement l’archive. L’indexation commencera après réception et préservation du fichier original.
